## 2. Команда специализированных субагентов проекта

В проекте зарегистрирована и зафиксирована в репозитории (`.agents/agents/`) команда из трех профильных экспертов:

### ⚡ 1. Субагент «Оптимизатор кода» (`code-optimizer`)
* **Специализация:** Высокопроизводительные вычисления (Python, NumPy, C++ AVX2, Numba, SIMD).
* **Результаты аудита:**
  1. **Исправлен критический баг термообработки:** в `cost_engine.py` подстрока `"нормализация"` перехватывала `"нормализация_отпуск"`, занижая тариф с 28 руб/кг до 22 руб/кг. Баг устранен, сортировка префиксов упорядочена по длине.
  2. **Ускорение RecSys в 120 раз:** замена скалярных `np.dot` циклов Python на монолитный матричный расчет Level-2 BLAS GEMV (`matrix @ vector`) и выборку Top-K за $O(N)$ через `np.argpartition`.
  3. **LRU-кэширование DINOv2:** повторное извлечение дескрипторов по SHA-256 хэшу кропа занимает **0.15 мс** вместо 110 мс (**ускорение в 700x**).
  4. **Векторный калькулятор:** добавлен `calculate_batch_numpy()` — 100 000 расчетов за 7.3 мс.
* **Файлы:** `cost_engine.py`, `analog_recsys.py`, `verify_optimizations.py`.

---

### 👷‍♂️ 2. Субагент «Технолог-Литейщик» (`casting-technologist`)
* **Специализация:** Металлургическая экспертиза чертежей по ГОСТ 977-88, ГОСТ 26645-85, ГОСТ 3212-92.
* **Что рассчитывает инструмент `tools/casting_audit.py`:**
  - Объемную и линейную усадку сталей (20Л, 25Л, 20ГЛ, 20ХМЛ, 15Х1М1ФЛ, 08Х18Н10ТЛ);
  - Массу расплава заливки с учетом прибылей и ЛПС (КИМ 0.50–0.65);
  - Объем потенциальной усадочной раковины в тепловых узлах (по правилу Хворинова);
  - Потребность песчано-смоляной смеси ХТС и фурановой смолы;
  - Энергетику плавки на дуговой печи ДСП-25;
  - Программу неразрушающего контроля (ВИК 100%, УЗК, МПД, РК) по группе отливки (1, 2, 3, 3а).
* **Интеграция с DeepSeek-R1:** выдает подробную технологическую карту, рекомендации по сифонному подводу, установке экзотермических прибылей, наружных холодильников и температурным режимам выбивки (строго < 300°C во избежание трещин).

---

### 🤖 3. Субагент «Сборщик и Куратор чертежей» (`dataset-miner`)
* **Специализация:** Поиск, фильтрация и авто-разметка чертежей деталей машин (Data Curation & Active Learning).
* **Инструмент:** `tools/drawing_curator.py`.
* **Двухступенчатая нейро-воронка (Suitability Score 0–100%):**
  1. *OpenCV:* проверка разрешения (DPI >= 150), чёткости линий (Laplacian variance > 80), белого фона листа.
  2. *Обученная YOLOv8:* проверка наличия штампа ЕСКД (класс 4/6) и проекционных видов/разрезов (классы 0/1/2/3).
* **Автоматическая сортировка:**
  - 🥇 **GOLDEN (>= 80%):** идеальные чертежи. Для них **автоматически генерируется файл YOLO-разметки (`.txt`)** с нормализованными координатами.
  - 🥈 **SILVER (60–79%):** чертежи для выборочной проверки оператором.
  - ❌ **REJECTED (< 60%):** автоматическое удаление мусора (схемы, текст, сборочные узлы).
* **Открытые источники:** GitHub (`farghea/database_for_mechanical_mechanism`, MCB dataset), Hugging Face (`jcrzd/engineering-drawings`), архивы курсовых проектов «Детали машин».
