## 🎯 Назначение веб-сервиса

Интерактивный веб-интерфейс (`web_app.py`) предназначен для инженеров-технологов и специалистов планово-экономического отдела сталелитейного завода **ООО «БВК»** (ПГ КОНАР) и для демонстрации проекта в **ЮУрГУ**.

Сервис позволяет:
1. Загрузить чертеж любого формата (PDF или растр PNG/JPG);
2. Мгновенно разметить функциональные зоны листа (YOLOv8 на видеокарте AMD RX 6600 через Vulkan);
3. Автоматически извлечь массу, марку стали, группу отливки по ГОСТ 977-88 и требования к контролю;
4. Сформировать прозрачную калькуляцию себестоимости по статьям затрат и полный технологический маршрут.

---

## 🧮 Формула и структура калькуляции (`cost_engine.py`)

Себестоимость уникальной стальной отливки рассчитывается по формуле:

$$C_{\text{итог}} = C_{\text{металл}} + C_{\text{плавка}} + C_{\text{оснастка}} + C_{\text{формовка}} + C_{\text{термообработка}} + C_{\text{контроль}} + C_{\text{мехобработка}} + C_{\text{риск}} + C_{\text{накладные}}$$

### Статьи затрат:
1. **Металл шихты и ферросплавы:**  
   $$M_{\text{расплава}} = \frac{M_{\text{детали}}}{\text{КИМ}}$$  
   Коэффициент выхода годного (КИМ): от $0.50$ (сложные корпуса/клапаны) до $0.65$ (фланцы).
2. **Плавка и энергозатраты:**  
   Расход электроэнергии на плавку в дуговой печи (ДСП) / индукционной печи (ИП) (~650 кВт·ч/т расплава) + электроды и огнеупорная футеровка.
3. **Модельная оснастка (Wood/Plastic/MDF ЧПУ):**  
   Для уникального единичного изделия — изготовление оснастки с нуля ($75\,000 - 250\,000$ ₽). При наличии близкого аналога применяется адаптация существующей оснастки (скидка до 65%).
4. **Формовка ХТС:**  
   Расход холоднотвердеющих песчано-смоляных смесей (4.2 т смеси на 1 т расплава).
5. **Термическая обработка:**  
   Нормализация с высоким отпуском, закалка или аустенизация (для нержавеющих сталей $12Х18Н12М3ТЛ$).
6. **Контроль качества по группам ГОСТ 977-88:**  
   * **Группа 1:** ВИК + механические испытания образцов.
   * **Группа 2:** ВИК + мех. свойства + МПД 20% сопряжений.
   * **Группа 3:** ВИК + 100% УЗК зон сопряжений стенок + МПД.
   * **Группа 3а (под давлением, АЭС, РМРС):** 100% ВИК, 100% УЗК (ГОСТ 24507-80, 2 группа), радиография (РК по ГОСТ 23055-78), капиллярный контроль (ЦД), гидроиспытания $P_{\text{пр}}$.
7. **Технологический риск брака:**  
   От $3\%$ (группа 1) до $12\%$ (группа 3а при жестком сплошном контроле).
8. **Общезаводские накладные расходы:**  
   $18\%$ от прямых затрат (содержание цехов, лаборатория, амортизация оборудования).

## 🖥️ Запуск сервиса

### Способ 1: Ярлык на рабочем столе
Двойной клик по ярлыку **«Сервис Ценообразования БВК»** на рабочем столе Windows.

### Способ 2: Через командную строку
```powershell
.\venv\Scripts\activate
python web_app.py
```
После запуска откройте в браузере адрес: **`http://127.0.0.1:7860`**.
