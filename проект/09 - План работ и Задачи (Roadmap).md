## 📌 Текущий прогресс проекта

### 1. Модуль детекции ЕСКД (YOLOv8)
- [x] Разработка синтетического генератора листов чертежей ЕСКД (`generate_yolo_dataset.py`)
- [x] Сбор и разметка датасета `dataset_yolo` (классы: `views_field`, `stamp`, `tech_req` и др.)
- [x] Обучение детектора `eskd_yolo_best.pt`
- [x] **Дообучение (Fine-Tuning) на расширенном датасете учебников и методичек (mAP50=99.5%, Precision=99.9%)**
- [x] **Экспорт в формат NCNN Vulkan (`eskd_yolo_best_ncnn_model`) для GPU AMD Radeon RX 6600**
- [x] **Инференс через шейдеры Vulkan со скоростью ~12.3 мс на чертеж**
- [x] Интеграция в `yolo_extractor.py`, `analogs/app/demo.py` и `web_app.py`
- [ ] Оптимизация работы с многостраничными PDF и нестандартными форматами (А0, удлиненные листы)

### 2. Модуль поиска деталей-аналогов
- [x] Конвертер 3D MCB моделей в векторные и растровые проекции (`pt_skript/convert_mcb_to_drawings.py`)
- [x] Исследование эмбеддингов DINOv2 и ArcFace для сравнения проекций
- [x] Эксперименты с мультимодальным поиском ruCLIP
- [x] **Настройка аппаратного ускорения PyTorch DirectML на AMD Radeon RX 6600 (`torch-directml`)**
- [x] **Адаптация скрипта `train.py` под автоопределение GPU AMD**
- [x] **Подключен скилл `recsys-pipeline-architect` для ранжирования деталей (Source -> Filter -> Scorer -> Selector)**
- [ ] Финальная генерация базы эмбеддингов `gallery.npz`
- [ ] Индексация заводской базы реальных отливок

### 3. Инженерный парсер и сопоставление с нормативной базой
- [x] Извлечение реквизитов штампа (марка стали, масса)
- [x] Парсинг технических требований: группа отливки по ГОСТ 977-88 / отраслевым нормам (`tech_parser.py`)
- [x] База правил: сопоставление требований с обязательными технологическими операциями (УЗК, термообработка, гидроиспытания)
- [x] Разработка металлургического калькулятора себестоимости БВК (`cost_engine.py`)

### 4. Веб-интерфейс и Отчетность
- [x] Базовое демо-приложение `analogs/app/demo.py`
- [x] Поддержка NCNN Vulkan в генераторе отчетов
- [x] Шаблон интерактивного отчета `report.html`
- [x] **Создан полнофункциональный интерактивный Веб-сервис технолога (`web_app.py` на Gradio)**
- [x] **Создан ярлык быстрого запуска «Сервис Ценообразования БВК» на рабочем столе**
- [ ] Интеграция с корпоративной ERP/1С системой (перспектива)

### 5. Расширение датасета и сбор методичек (Miner)
- [x] Создан скрипт веб-поиска и парсинга методичек `manual_dataset_miner.py`
- [x] Автоматическое извлечение чертежей и разметка в формате YOLO через Vulkan NCNN
- [x] Нарезка полей проекций $512\times512$ для DINOv2
- [x] Парсинг марок сталей, групп контроля и термообработки в JSON-базу знаний
- [x] **Скачано 8 профильных методичек по литейному производству и машиностроению**
- [x] **Обучающий датасет расширен до 512 чертежей (добавлено 84 новых листа)**
- [x] Установлена среда Node.js LTS (v26.13.0) и настроены MCP-серверы: GitHub MCP и Exa MCP
- [ ] Очередной цикл дообучения YOLO на обновленном датасете 512+ чертежей
