## 📌 Текущий прогресс проекта

### 1. Модуль детекции ЕСКД (YOLOv8)
- [x] Разработка синтетического генератора листов чертежей ЕСКД (`generate_yolo_dataset.py`)
- [x] Восстановление 420 чертежей крепежа/деталей и генерация 446 синтетических листов из базы 3D нормалей
- [x] **Масштабирование датасета до 1 000 чертежей (851 train, 149 val)**
- [x] **Обучение модели `eskd_yolo_best.pt` на 1 000 чертежах (Precision: 99.9%, Recall: 100%, mAP50: 99.5%, mAP50-95: 98.2%)**
- [x] **Создание пайплайна облачного обучения в Google Colab на GPU Tesla T4 (`train_yolo_in_colab.ipynb`)**
- [x] Устранение платформозависимых багов кэширования Ultralytics (`train.cache`/`val.cache`)
- [x] Экспорт в формат NCNN Vulkan (`eskd_yolo_best_ncnn_model`) для GPU AMD Radeon RX 6600
- [x] Инференс через шейдеры Vulkan со скоростью ~12.3 мс на чертеж
- [x] Интеграция в `yolo_extractor.py`, `analogs/app/demo.py` и `web_app.py`

### 2. Модуль поиска деталей-аналогов (RecSys CBR & DINOv2)
- [x] Конвертер 3D MCB моделей в векторные и растровые проекции
- [x] Исследование эмбеддингов DINOv2 и ArcFace для сравнения проекций
- [x] Эксперименты с мультимодальным поиском ruCLIP
- [x] Подключен скилл `recsys-pipeline-architect` для 6-стадийного ранжирования (Source -> Hydrator -> Filter -> Scorer -> Selector -> SideEffect)
- [x] Мультимодальный скоринг аналогов (геометрия 50% + сталь 25% + масса 15% + группа контроля 10%)
- [ ] Финальная генерация полной базы эмбеддингов `gallery.npz`

### 3. Инженерный парсер и калькулятор себестоимости БВК
- [x] Извлечение реквизитов штампа (марка стали, масса)
- [x] Парсинг технических требований: группа отливки по ГОСТ 977-88 / отраслевым нормам (`tech_parser.py`)
- [x] База правил: сопоставление требований с обязательными технологическими операциями (УЗК, термообработка, гидроиспытания)
- [x] Разработка металлургического калькулятора себестоимости БВК (`cost_engine.py`)
- [x] Генерация коммерческих предложений (ТКП) в PDF и Excel

### 4. Веб-интерфейс и Отчетность
- [x] Интерактивный Веб-сервис технолога (`web_app.py` на Gradio)
- [x] Автоматический QA-Бот и стресс-тестирование на 30 реальных чертежах (`batch_eval_bot.py`)
- [x] Экспорт интерактивного HTML отчета (`report.html`)

### 5. Интеграция инструментов и MCP Серверы
- [x] Синхронизация репозитория на GitHub: `https://github.com/yaroslikch-glitch/pricing_of_a_unique_cast_product`
- [x] Интеграция бесплатного DeepSeek API через локальный прокси ForgetMeAI (`http://127.0.0.1:9655`)
- [x] Разработка Antigravity MCP сервера DeepSeek (`deepseek-mcp`) с 4 инструментами: chat, reason (R1), debug_code, web_search
- [x] Настройка Obsidian MCP сервера (`read_notes`, `search_notes`) для синхронизации базы знаний
- [x] Настройка Colab MCP сервера
