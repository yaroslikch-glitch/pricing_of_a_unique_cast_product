## 💻 Конфигурация системы

- **ОС:** Windows 10/11 x64
- **Видеокарта:** AMD Radeon RX 6600 (8 GB VRAM, архитектура RDNA 2 / Navi 23)
- **Стек ускорения:**
  - **Vulkan 1.4 + NCNN:** для сверхбыстрого инференса YOLO (детекция чертежей ~12.3 мс на AMD RX 6600);
  - **DirectML (`torch-directml`):** для обучения и вычислений PyTorch на GPU AMD под Windows.
- **Python:** 3.12 (установлен в виртуальное окружение `venv`).

---

## 🖥️ Запуск Интерактивного веб-сервиса оценки

Самый простой способ — двойной клик по ярлыку на рабочем столе:
- **`Сервис Ценообразования БВК.lnk`** (или запуск `run_app.bat` в папке проекта).
- Сервис откроется в браузере по адресу `http://127.0.0.1:7860`.

## ⚡ Основные команды работы

### 1. Анализ чертежа через Vulkan (NCNN):
```powershell
# Нарезка элементов листа чертежа на GPU через Vulkan:
python yolo_extractor.py --source "path/to/drawing.pdf" --weights eskd_yolo_best_ncnn_model --out layers_out/

# Запуск демо и генерация отчета с моделью Vulkan:
python analogs/app/demo.py "path/to/drawing.pdf" --yolo eskd_yolo_best_ncnn_model --out report.html
```

### 2. Экспорт моделей в Vulkan NCNN:
```powershell
python -c "from ultralytics import YOLO; YOLO('eskd_yolo_best.pt').export(format='ncnn')"
```

### 3. Обучение метрической сети (DINOv2 / ArcFace):
```powershell
python analogs/train/train.py --data "path/to/data" --model dinov2 --run full
```
