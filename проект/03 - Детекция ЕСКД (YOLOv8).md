## 🎯 Задача модуля детекции

Инженерные чертежи по **ГОСТ 2.104** имеют сложную неоднородную верстку:
- Поле видов детали (главный вид, разрезы, сечения, выносные элементы);
- Штамп (основная надпись) в правом нижнем углу;
- Технические требования над штампом;
- Таблицы параметров, неуказанная шероховатость и т.д.

В проекте используется **обученная нейросеть YOLOv8**, которая локализует ключевые функциональные зоны листа с рекордной точностью **mAP@50 = 99.5%**.

---

## 🏷️ Классы объектов (BBox Classes)

| ID класса | Имя класса | Описание и назначение |
| :---: | :--- | :--- |
| **0** | `views_field` | Поле проекционных видов изделия (отправляется на визуальный поиск аналогов) |
| **1** | `view_front` | Главный проекционный вид детали |
| **2** | `view_top` | Проекционный вид сверху |
| **3** | `view_left` | Проекционный вид слева |
| **4** | `stamp` | Основная надпись чертежа (ГОСТ 2.104) — марка стали, масса, масштаб, шифр |
| **5** | `tech_req` | Блок технических требований — виды контроля, термообработка, покрытия |
| **6** | `stamp_extra` | Дополнительные графы штампа (левая рамка) |

## 📊 Результаты обучения на полном датасете (1 000 чертежей)

Обучающий датасет был масштабирован до **1 000 полных чертежей** (851 train, 149 val):
- Восстановлены 420 отфильтрованных чертежей крепежа и деталей;
- 446 синтетических листов чертежей со сгенерированными проекциями на базе нормалей 3D моделей;
- 47 процедурных чертежей реальных отливок (фланцы, крыльчатки, втулки, корпусы клапанов, валы, кронштейны, плиты).

**Метрики текущей обученной модели (`eskd_yolo_best.pt`):**
- **Precision (Точность):** `0.999` (99.9%)
- **Recall (Полнота охвата):** `1.000` (100%)
- **mAP@50:** `0.995` (99.5%)
- **mAP@50-95:** `0.982` (98.2%)
- **Размер весов:** 6.2 МБ (YOLOv8 Nano, идеален для быстрого инференса)

## ⚡ Аппаратное ускорение на AMD Radeon RX 6600 (Vulkan NCNN)

Для видеокарты **AMD Radeon RX 6600** реализован и протестирован конвейер инференса через **Vulkan SPIR-V compute shaders**:
1. Модель `eskd_yolo_best.pt` экспортирована в оптимизированный формат **NCNN** (`eskd_yolo_best_ncnn_model`).
2. Скорость работы на видеокарте: **~12.3 мс на один лист чертежа** (инференс выполняется за доли секунды на GPU).
3. Интегрирована поддержка прямого запуска через `yolo_extractor.py`, `demo.py` и `web_app.py`:
   ```powershell
   python yolo_extractor.py --source "path/to/drawing.png" --weights eskd_yolo_best_ncnn_model --out layers_out/
   ```

## ☁️ Обучение в Google Colab (GPU NVIDIA Tesla T4)

Для быстрого обучения на облачных GPU создан Jupyter-ноутбук `train_yolo_in_colab.ipynb`:
- **Среда:** Tesla T4 (15 ГБ VRAM), CUDA 12.x;
- **Скорость обучения:** ~1-2 минуты на 30 эпох для 1 000 изображений;
- **Решение проблемы кроссплатформенных путей Ultralytics:**
  - При переносе с Windows на Linux в Colab библиотека Ultralytics читала локальные кэши `train.cache`/`val.cache` с путями вида `C:/Users/...`, что вызывало `FileNotFoundError`.
  - В репозитории и ноутбуке реализована автоматическая очистка кэшей (`!rm -f dataset_yolo/labels/*.cache`), переход на относительные пути в `dataset.yaml` и динамическое определение путей.
  - Веса `best.pt` после окончания тренировки автоматически скачиваются в браузер или сохраняются на Google Drive.

## 🛠️ Скрипты и реализация

### 1. Извлечение элементов: `yolo_extractor.py`
Класс `ESKDExtractor` выполняет:
- Загрузку чертежа из PDF через `PyMuPDF` или из PNG/JPG;
- Инференс весов (`.pt` или NCNN Vulkan `_ncnn_model`) с порогом уверенности `conf=0.35`;
- Кроп каждого элемента в `extracted_elements/`;
- Подготовку квадратной канвы `512x512` с белым фоном для поля видов (`prepare_dinov2_canvas`).

### 2. Экспорт модели в Vulkan NCNN:
```python
from ultralytics import YOLO
model = YOLO('eskd_yolo_best.pt')
model.export(format='ncnn')
```

### 3. Скрипт обучения: `train_yolo.py`
Запуск обучения/дообучения модели:
```powershell
python train_yolo.py --data dataset_yolo/dataset.yaml --epochs 30 --imgsz 640
```
