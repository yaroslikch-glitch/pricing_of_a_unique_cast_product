## 🎯 Задача модуля детекции

Инженерные чертежи по **ГОСТ 2.104** имеют сложную неоднородную верстку:
- Поле видов детали (главный вид, разрезы, сечения, выносные элементы);
- Штамп (основная надпись) в правом нижнем углу;
- Технические требования над штампом;
- Таблицы параметров, неуказанная шероховатость и т.д.

В проекте используется **обученная нейросеть YOLOv8**, которая локализует ключевые функциональные зоны листа с точностью выше 95%.

## ⚡ Аппаратное ускорение на AMD Radeon RX 6600 (Vulkan NCNN)

Для видеокарты **AMD Radeon RX 6600** реализован и протестирован конвейер инференса через **Vulkan SPIR-V compute shaders**:
1. Модель `eskd_yolo_best.pt` экспортирована в оптимизированный формат **NCNN** (`eskd_yolo_best_ncnn_model`).
2. Скорость работы на видеокарте: **~12.3 мс на один лист чертежа** (инференс выполняется за доли секунды на GPU).
3. Интегрирована поддержка прямого запуска через `yolo_extractor.py`, `demo.py` и `web_app.py`:
   ```powershell
   python yolo_extractor.py --source "path/to/drawing.png" --weights eskd_yolo_best_ncnn_model --out layers_out/
   ```

### ❓ Почему обучение (Training) на CPU, а инференс (Inference) на GPU?
- **Инференс (применение)**: Модель работает через **Vulkan NCNN**. Шейдеры Vulkan скомпилированы напрямую под архитектуру RDNA2 (Navi 23) видеокарты AMD Radeon RX 6600.
- **Обучение (Training)**:
  - Под Windows для карт AMD отсутствует официальный ROCm (он существует только для Linux).
  - Доступный бэкенд PyTorch для Windows — **Microsoft DirectML** (`torch-directml`).
  - При расчете функции потерь YOLOv8 (`v8DetectionLoss` / `TaskAlignedAssigner`) вызываются специфические операторы `unique(return_counts=True)` и многомерный `scatter_add_(-1)`.
  - Текущая версия драйвера DirectML от Microsoft не имеет встроенных ядер для этих операторов (`RuntimeError: DirectML scatter doesn't allow partially modified dimensions`).
  - Поэтому дообучение YOLO выполняется на 6-ядерном / 12-поточном процессоре **AMD Ryzen 5 5600**, что для 483 чертежей занимает всего ~2–3 минуты, а полученная модель сразу компилируется в **Vulkan NCNN** для работы на RX 6600.
  - При этом модели метрического поиска (ResNet50 / DINOv2 эмбеддинги) не содержат таких операторов и могут обучаться на DirectML.

## 📊 Результаты дообучения (Fine-Tuning на расширенном датасете)

После добавления чертежей из методичек ЮУрГУ и учебников по машиностроению датасет составил 483 обучающих и 75 валидационных изображений. 

**Метрики дообученной модели (`eskd_finetuned`):**
- **Precision (Точность):** `0.999` (99.9%)
- **Recall (Полнота охвата):** `1.000` (100%)
- **mAP@50:** `0.995` (99.5%)
- **mAP@50-95:** `0.993` (99.3%)
- **Время инференса (RX 6600 Vulkan):** `12.3 мс` (препроцессинг 2.5 мс, инференс 12.3 мс, постпроцессинг 1.5 мс)

## 🛠️ Скрипты и реализация

### 1. Извлечение элементов: `yolo_extractor.py`
Класс `ESKDExtractor` выполняет:
- Загрузку чертежа из PDF через `PyMuPDF` или из PNG/JPG;
- Инференс весов (`.pt` или NCNN Vulkan `_ncnn_model`) с порогом уверенности `conf=0.35`;
- Кроп каждого элемента в `extracted_elements/`;
- Подготовку квадратной канвы `512x512` с белым фоном для поля видов (`prepare_dinov2_canvas`).

### 2. Экспорт модели в Vulkan NCNN:
```python
from ultralytics import YOLO
model = YOLO('eskd_yolo_best.pt')
model.export(format='ncnn')
```

### 3. Скрипт обучения: `train_yolo.py`
Запуск обучения/дообучения модели:
```powershell
python train_yolo.py --data dataset_yolo/dataset.yaml --epochs 30 --imgsz 640
```
