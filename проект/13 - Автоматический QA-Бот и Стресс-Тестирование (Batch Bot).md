## 🎯 Назначение QA-Бота (`batch_eval_bot.py`)

Для проверки стабильности и качества работы пайплайна разработан автономный бот пакетного тестирования:
1. **Пакетный прогон:** Автоматически подает на вход веб-сервиса выборку чертежей (из валидационной выборки, методичек и реальных сканов).
2. **Стресс-тестирование:** Проверяет устойчивость пайплайна на сложных чертежах (отдельные виды без штампа, рукописные заметки, чертежи с нестандартными рамками).
3. **Фиксация результатов:** Сохраняет результаты каждого прогона в формате JSON ([`eval_results.json`](file:///C:/Users/Yarchik/OneDrive/Desktop/проект/bot_eval_results/eval_results.json)), аннотированные изображения в [`bot_eval_results/annotated/`](file:///C:/Users/Yarchik/OneDrive/Desktop/проект/bot_eval_results/annotated) и формирует Markdown-отчет с точками роста.
4. **Обратная связь для кода:** На основе собранных аномалий бот формирует конкретные рекомендации по доработке парсера ГОСТов и калькулятора.

## 🚀 Команды запуска

```powershell
# Активация окружения:
.\venv\Scripts\activate

# Запуск бота на выборке из 12 чертежей:
python batch_eval_bot.py --count 12

# Запуск на произвольной папке с чертежами:
python batch_eval_bot.py --input-dir "path/to/drawings" --out bot_eval_results
```

---

## 📊 Структура генерируемого отчета

Каждый запуск создает в папке `bot_eval_results/`:
- `eval_results.json` — машиночитаемый лог со всеми обнаруженными классами, массами, марками сталей и себестоимостью.
- `eval_report.md` — аналитический отчет:
  - Доля успешных распознаваний (Pass Rate);
  - Среднее время инференса на AMD RX 6600 (Vulkan);
  - Детализированная таблица по каждому чертежу;
  - Секция **«Выявленные точки роста и Рекомендации по коду»**.
- `annotated/*.png` — визуализированные чертежи с bounding box'ами всех элементов ЕСКД.
