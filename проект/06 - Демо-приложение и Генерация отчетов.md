## 🖥️ Веб-демо (`analogs/app/demo.py`)

Демонстрационное приложение объединяет все компоненты системы в единый интерактивный интерфейс:
1. Загрузка чертежа (PDF или изображение);
2. Визуализация результатов детекции ЕСКД (рамочная разметка поля видов, штампа, ТТ);
3. Отображение найденных литых деталей-аналогов из базы с указанием процента сходства;
4. Интерактивная карточка оценки себестоимости с расшифровкой технологических операций.

---

## 📄 Формирование отчетов

Приложение умеет генерировать готовые отчеты для технологов:
- `report.html` — интерактивный HTML-отчет с динамическими графиками, превью вырезанных зон и таблицей расчета;
- `test_report.html` / `test_report_pdf.html` — шаблоны для выгрузки в PDF и согласования с финансовым отделом завода.

### Команда запуска:
```powershell
python analogs/app/demo.py "path/to/drawing.pdf" --out report.html
```
