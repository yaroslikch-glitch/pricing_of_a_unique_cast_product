# Архитектура системы

## Поток обработки чертежа

```
PDF / картинка листа
  │
  ├─ разбор листа (без нейросетей): рамка, масштаб по основной надписи 185×55 мм,
  │  исключение штампа, доп. графы, технических требований и надписей
  │        │
  │        ▼
  │   поле видов 512×512 ──► [1] DINOv2 ──► эмбеддинг ──► kNN по базе ──► топ-5 аналогов
  │                                                        │                класс (голосование)
  │                                                        └─ сходство < порога ─► «новый класс»
  │
  └─ основная надпись ──► текстовый слой PDF (правила) ─┐
                     └──► OCR (скан, картинка)* ────────┴─► обозначение, наименование,
                                                             материал, масса, масштаб
                                                                   │
                         [2] ruCLIP: «наименование ↔ форма» ◄──────┘ (флаг несоответствия)
                                                                   │
                         пересортировка аналогов по материалу и массе (вторичный признак)
```

## Почему геометрия первична
- Требование заказчика (встреча 16.10): «используется именно чертёж и уже во вторую очередь габариты, массу и материал».
- Трудоёмкость литья (формовка, стержни, литниковая система) определяется формой детали.
- Наименование ненадёжно («Корпус», «Деталь»), OCR ошибается. Поэтому текст только уточняет порядок аналогов
  (вес не больше 0,02 к сходству) и на класс не влияет.

\* На этапе 1 — Tesseract, на этапе 2 — Qwen3-VL.

## Этап 1: выбор модели геометрии
Сравнивались DINOv2, ruCLIP и ResNet50 (базовая линия) в одинаковых условиях (эксперимент v1).
DINOv2 лучшая по всем метрикам и уже без дообучения даёт 83% верных классов. ResNet50 уступает
по поиску аналогов (Recall@5 0,90 против 0,96) и по распознаванию нового класса (AUROC 0,85 против 0,95).
DINOv3 не рассматривается: лицензия запрещает применение в атомной и военной отраслях.

## Этап 2: три нейросети — три роли (ограничение проекта)

| № | Модель | Роль сейчас | Роль на этапе ценообразования |
|---|---|---|---|
| 1 | DINOv2 ViT-B/14 | Поиск аналогов, класс, «новый класс» | Та же: аналоги — основа оценки |
| 2 | ruCLIP ViT-L/14-336 (отечественная) | Проверка «наименование ↔ форма», текстовый запрос к базе | Связь чертежа с документами |
| 3 | Qwen3-VL-4B (локально), вместо ResNet50 | Чтение штампа со сканов | Чтение ТЗ/ТТ, работы, влияющие на цену; RAG по регламентам |

Без нейросетей: разбор листа, текстовый слой PDF, пересортировка, расчёт стоимости
(пересчёт фактических данных аналогов, далее — градиентный бустинг).

## Порог «нового класса»
5-й перцентиль сходства каждого чертежа базы с его ближайшим соседом (на текущей базе 0,887).
Пересчитывается автоматически при замене базы на чертежи БВК.
