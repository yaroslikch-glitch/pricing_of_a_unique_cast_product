# Синтетический датасет чертежей ЕСКД

| Шаг | Скрипт | Что делает |
|---|---|---|
| 1 | `select_mcb.py` | Отбирает модели MCB по 8 классам (не больше 120 с каждой исходной папки) |
| 2 | `eskd_gen.py` | По 3D-модели строит лист: ориентация по PCA, 3 вида (метод первого угла), полуразрез тел вращения со штриховкой, размеры, рамка и штамп по ГОСТ 2.104, ТТ. Сохраняет PDF листа и PNG поля видов 512×512 |
| 3 | `finalize.py` | Убирает почти одинаковые чертежи (косинус > 0,95 на 48×48), делит 70/15/15 по классам, строит превью |
| 4 | `relabel.py` | Уточняет названия классов 06/07 и исключает стержни (средний габарит < 6% наибольшего) |

Классы (классификатор ЕСКД, 71–74): 01 диски и фланцы, 02 колёса и шкивы, 03 втулки и стаканы,
04 валы и оси, 05 корпусные, 06 петли и кронштейны, 07 рычаги и крюки, 08 плоские фасонные.

Итог: 2 506 чертежей (train 1 754 / val 377 / test 375).

На листах нет данных реальных организаций и людей: организация «Учебный проект», обозначения `SYN.<класс>.<номер>`.
Масса детали считается по объёму модели и плотности стали. «Фактические» масса отливки и трудоёмкость — синтетические (`*_SYNTH`).

Известное ограничение: в основной надписи генератора есть отклонения от ГОСТ 2.104 (часть линий левой
части штампа). На обучение не влияет: сеть видит только поле видов.
