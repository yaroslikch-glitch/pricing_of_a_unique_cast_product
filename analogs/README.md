# Поиск аналогов литых деталей по чертежу

Учебно-производственный проект ЮУрГУ с индустриальным партнёром ООО «БВК» (ПГ «КОНАР», Челябинск).

**Задача этапа.** По новому чертежу в PDF найти в базе уже изготовленных деталей похожие по геометрии,
извлечь со штампа габариты, массу и материал, а если аналога нет, предложить создать новый класс.
Следующий этап — оценка трудоёмкости и стоимости по фактическим данным найденных аналогов.

Реальные чертежи БВК будут предоставлены после NDA. До этого система разрабатывается на синтетическом
датасете: **реальная геометрия деталей** из Mechanical Components Benchmark (Kim et al., ECCV 2020),
по которой сгенерированы листы по ЕСКД (рамка, основная надпись по ГОСТ 2.104, виды, разрезы, размеры).

## Этап 1: какая нейросеть лучше определяет геометрию

Три модели обучены и проверены в одинаковых условиях: эмбеддинг поля видов → поиск ближайших в базе (kNN),
затем дообучение с ArcFace.

| Модель | Происхождение | Лицензия |
|---|---|---|
| **DINOv2 ViT-B/14** | Meta, 2023, самообучение на 142 млн изображений | Apache-2.0 |
| **ruCLIP ViT-L/14-336** | Sber AI, отечественная, обучена на парах «картинка — русский текст» | Apache-2.0 |
| **ResNet50** | классическая свёрточная сеть (2015), базовая линия | Apache-2.0 (timm) |

### Результаты (тест — 375 чертежей, 8 классов)

| Модель | Этап | Recall@1 | Recall@5 | Accuracy | Macro-F1 | AUROC «новый класс» |
|---|---|---|---|---|---|---|
| DINOv2 | без дообучения | 0.803 | 0.957 | 0.832 | 0.799 | 0.957 |
| **DINOv2** | **дообучение** | **0.821** | 0.933 | **0.840** | **0.811** | 0.951 |
| ruCLIP | без дообучения | 0.765 | 0.960 | 0.784 | 0.742 | 0.914 |
| ruCLIP | дообучение | 0.765 | 0.925 | 0.768 | 0.731 | 0.888 |
| ResNet50 | без дообучения | 0.784 | 0.925 | 0.781 | 0.737 | 0.880 |
| ResNet50 | дообучение | 0.771 | 0.901 | 0.803 | 0.771 | 0.852 |

**Вывод.** DINOv2 — основная модель геометрии: лучшая по всем метрикам, без дообучения уже 83% верных классов,
новые классы добавляются пополнением базы без переобучения. ruCLIP (отечественная) не уступает по Recall@5.
ResNet50 уступает по поиску аналогов и по распознаванию нового класса и в целевую систему не переходит.
Подробно: [experiments/v1_2026-10-29](experiments/v1_2026-10-29/README.md).

## Этап 2 (после передачи чертежей БВК и расширения ТЗ до ценообразования)

Ограничение проекта — три нейросети. Место ResNet50 занимает модель чтения документов:

| Роль | Модель |
|---|---|
| Геометрия: аналоги, класс, «новый класс» | DINOv2 |
| Связь чертежа и текста, отечественная | ruCLIP |
| Чтение документов: штамп со сканов, ТЗ, ТТ, регламенты | Qwen3-VL (локально, LM Studio, Apache-2.0) |

Заготовка этапа 2 — в ветке `stage2-qwen`. Подробнее: [docs/architecture.md](docs/architecture.md).

## Структура

```
data_gen/      отбор моделей MCB, генерация листов ЕСКД, разбиение train/val/test
train/         обучение и оценка (kNN + ArcFace), ноутбук Kaggle, проверка ПК с GPU
experiments/   результаты экспериментов (метрики, матрицы ошибок, примеры аналогов)
app/           демо: PDF/картинка -> штамп -> класс -> топ-5 аналогов или «новый класс»
docs/          архитектура и решения
```

## Быстрый старт

```
pip install -r requirements.txt          # PyTorch — отдельно, см. train/INSTALL.md
python data_gen/select_mcb.py --a MCB_A/dataset_org_norm --b MCB_B --out mcb_raw
python data_gen/eskd_gen.py --src mcb_raw --out out --workers 4
python data_gen/finalize.py --out out --thr 0.95
python data_gen/relabel.py --out out
python train/train.py --data out --model dinov2 --run full      # dinov2 | ruclip | resnet50
python app/demo.py --model results/dinov2_full/best.pt --gallery results/dinov2_full/gallery.npz --data out чертёж.pdf
```

Обучение без своей видеокарты — ноутбук `train/bvk_kaggle_train.ipynb` (Kaggle, GPU T4 x2).

## Данные и ограничения
- Датасет, веса моделей и база эмбеддингов в репозиторий не входят (размер, лицензия MCB) и хранятся отдельно.
- Чертежи БВК не загружаются ни в облако, ни в этот репозиторий (NDA). Обучение на них — только на локальном ПК.
- Фактические «масса отливки» и «трудоёмкость» в учебной базе синтетические (`*_SYNTH`) и показывают только формат данных.
