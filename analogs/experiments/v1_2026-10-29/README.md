# Эксперимент v1 — выбор модели геометрии (29.10.2026)

**Код:** коммит «Обучение и оценка…» (`train/train.py`, `train/bvk_kaggle_train.ipynb`), модели DINOv2, ruCLIP, ResNet50.
**Где:** Kaggle, 2× NVIDIA T4, fp16. **Данные:** синтетический датасет v1, 2 506 чертежей, 8 классов (1 754 / 377 / 375).

**Протокол.** Эмбеддинг поля видов → kNN по галерее (train+val), класс — взвешенное голосование топ-5.
Baseline — предобученная модель без дообучения. Fine-tune — последние блоки (DINOv2 — 6, ruCLIP — 4, ResNet50 — вся сеть)
и проекция 512 с ArcFace, баланс классов, ранняя остановка по val. Режим `open`: класс 06 скрыт при обучении и
в галерее, порог «нового класса» выбирается на val (95% известных проходят), проверяется на test.

## Выводы
1. **DINOv2 — основная модель:** лучшая по всем метрикам, без дообучения уже 83% верных классов.
2. **Дообучение дало ≤ 2 п.п.** — в пределах разброса на 375 тестовых чертежах (±2 п.п.). По логам —
   переобучение: loss падает в 3–4 раза, val стоит.
3. **Основной источник ошибок — пересечение классов в разметке MCB:** фланцевые корпуса подшипников
   (05) против фланцев (01), краны с рукоятками в папке Lever (07) против кранов (05). Найденные аналоги
   при этом геометрически похожи (см. `*/analogs_finetuned.png`).
4. ruCLIP (отечественная) на уровне DINOv2 по Recall@5, но на 5 п.п. ниже по классу.
5. ResNet50 хуже по поиску и по распознаванию нового класса; из системы исключена.
