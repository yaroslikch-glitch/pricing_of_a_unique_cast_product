# Ценообразование уникального литого изделия

> **Индустриальный партнёр:** ООО «БВК» (ПГ КОНАР, г. Челябинск)  
> **Учебный трек:** ЮУрГУ (Южно-Уральский государственный университет)

---

## 🎯 Проблема и бизнес-задача

Сталелитейный завод **ООО «БВК»** — современное высокотехнологичное производство в составе Промышленной группы КОНАР. Завод производит крупногабаритное и ответственное литье для нефтегазовой, энергетической и судостроительной отраслей. 

Каждое новое изделие в этой сфере является **уникальным**: даже небольшое отличие в марке стали, группе отливки (ГОСТ 977-88) или требованиях к неразрушающему контролю (УЗК, РК) требует полного пересчета себестоимости. Ручная оценка специалистами ПЭО и металлургами занимает от нескольких дней до недели, при этом риск ошибки или занижения цены ведет к многомиллионным убыткам.

---

## 💡 Что делает система

Сервис **не рассчитывает стоимость вслепую**, а реализует сквозной инженерно-аналитический конвейер:

1. **Анализ чертежа (YOLOv8 layout analysis):** детектирует зоны листа ЕСКД (ГОСТ 2.104) — поле видов, штамп и блок технических требований с точностью **mAP@50 = 99.5%**.
2. **Инженерный парсер нормативной базы:** извлекает марку стали (`20ГЛ`, `12Х18Н9ТЛ` и др.), массу отливки, группу контроля по ГОСТ 977-88 и требования к термообработке.
3. **Калькулятор себестоимости БВК:** рассчитывает нормативную себестоимость по 9 статьям металлургического передела (шихта, формовка ХТС Альфасет, плавка в ДСП, термообработка, лаборатория НК, общезаводские расходы).
4. **Рекомендательная система аналогов (CBR & DINOv2):** сравнивает геометрию чертежа с заводским архивом, находит ближайшие изготовленные ранее детали и выявляет наличие готовой модельной оснастки на складе (потенциальная экономия до 300 000+ руб. и сокращение срока подготовки производства на 20–30 дней).
5. **Экспорт ТКП:** автоматически формирует официальное Технико-коммерческое предложение (PDF) и калькуляционную ведомость (Excel) по корпоративным стандартам завода.

## 🚀 Быстрый старт на новом компьютере

### 1. Клонирование репозитория
```bash
git clone https://github.com/yaroslikch-glitch/pricing_of_a_unique_cast_product.git
cd pricing_of_a_unique_cast_product
```

### 2. Создание и активация окружения
```bash
python -m venv venv
# Windows:
.\venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
# Установка PyTorch:
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121

# Установка зависимостей проекта:
pip install -r requirements.txt
```

### 4. Запуск веб-сервиса ценообразования (Web UI)
```bash
# Запуск интерактивного интерфейса:
python web_app.py
# Или через Windows-батник:
run_app.bat
```
Интерфейс откроется в браузере по адресу: `http://127.0.0.1:7860`.

### 5. Автономное тестирование чертежей (QA Bot)
```bash
# Пакетное тестирование чертежей с генерацией аналитического отчета:
python batch_eval_bot.py --count 10
# Или через Windows-батник:
run_batch_bot.bat
```
Результаты сохраняются в `bot_eval_results/eval_report.md`.

### 6. Обучение модели детекции ЕСКД
* **В облаке на бесплатном GPU (рекомендуется):** откройте [`train_yolo_in_colab.ipynb`](train_yolo_in_colab.ipynb) в Google Colab на GPU Tesla T4.
* **Локально на процессоре:**
  ```bash
  python tools/train_yolo.py --data dataset_yolo/dataset.yaml --epochs 30 --imgsz 640
  ```

### 7. База знаний проекта в Obsidian
Вся техническая документация, регламенты ГОСТ 977-88, архитектура CBR RecSys и инструкции собраны в каталоге `проект/` (открывается напрямую через приложение Obsidian как Vault).
