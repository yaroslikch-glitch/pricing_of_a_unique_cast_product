# Ценообразование уникального литого изделия

Учебный проект ЮУрГУ (трек индустриального партнёра) совместно с ООО «БВК» (ПГ КОНАР, г. Челябинск).

## Проблема

Сталелитейный завод ООО «БВК» — дочернее предприятие КОНАР. Завод работает по госконтрактам: получает заявку на отлив уникального изделия (даже если требования к изделию немного отличаются, оно считается уникальным, потому что стоимость его производства нужно заново пересчитать). К изделию из литья предъявляются высокие требования. Специалисту нужно сделать примерную оценку стоимости такого изделия. Стоимость строится на основе изучения большого количества технических регламентов: для судостроения одни регламенты, для АЭС другие и т.д. По оценкам специалистов процедура оценки изделия может занимать несколькими специалистами от нескольких дней до недели. Иногда предварительная стоимость является заниженной по отношению к реально затраченным финансам, что естественно приводит к убыткам. Необходимо создать рекомендательную систему, которая бы предлагала специалисту стоимость изделия.

## Что делает сервис

Сервис **не рассчитывает стоимость вслепую**. Он помогает специалисту ничего не упустить:

1. Принимает техническое задание и чертёж литой детали (PDF/изображение);
2. Анализирует структуру листа ЕСКД с помощью **YOLOv8** (автоматически детектирует поле проекционных видов, основную надпись/штамп ГОСТ 2.104 и технические требования);
3. Извлекает из чертежа и ТЗ требования к изделию и свойства заготовки;
4. Формирует перечень технологических операций, контроля и испытаний, обусловленных этими требованиями;
5. Для каждой операции показывает нормативное основание: требование ТЗ или чертежа и пункт регламентного документа;
6. Находит визуально и конструктивно похожие ранее выполненные изделия (через эмбеддинги **DINOv2** / ArcFace) и показывает отличия;
7. Формирует итоговую интерактивную карточку оценки с выгрузкой отчета.

## Структура репозитория

`
├── analogs/                      # Основной модуль подбора литых деталей-аналогов
│   ├── app/                     # Веб-демо и генерация отчетов
│   │   ├── demo.py              # Точка входа: анализ чертежа, детекция YOLO, генерация HTML
│   │   └── eskd_yolo_best.pt    # Веса детектора ЕСКД для приложения
│   ├── data_gen/                # Генераторы синтетических видов и парсинга 3D MCB
│   ├── experiments/             # Эксперименты с эмбеддингами (CLIP, DINOv2)
│   └── train/                   # Пайплайны обучения метрических моделей
├── dataset_yolo/                 # Синтетический датасет чертежей ЕСКД для YOLOv8
├── eskd_yolo_best.pt             # Обученная модель YOLOv8 (Layout Analysis ЕСКД)
├── generate_yolo_dataset.py      # Многопроцессорный генератор чертежей ЕСКД с разметкой
├── train_yolo.py                 # Скрипт обучения YOLOv8
├── yolo_extractor.py             # Утилита нарезки чертежа (поле видов, штамп, техтребования)
└── requirements.txt              # Зависимости Python
`

## Быстрый старт на новом компьютере

### 1. Клонирование репозитория
`ash
git clone https://github.com/yaroslikch-glitch/pricing_of_a_unique_cast_product.git
cd pricing_of_a_unique_cast_product
`

### 2. Создание и активация окружения
`ash
python -m venv venv
# Windows:
.\venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate
`

### 3. Установка зависимостей
`ash
# Установка PyTorch (с поддержкой GPU CUDA или CPU):
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121

# Установка остальных библиотек:
pip install -r requirements.txt
`

### 4. Запуск анализа чертежа (Инференс)
`ash
# Генерация интерактивного HTML-отчета по чертежу (PDF или PNG):
python analogs/app/demo.py "path/to/drawing.pdf" --out report.html

# Нарезка слоев чертежа в отдельные файлы через YOLO Extractor:
python yolo_extractor.py "path/to/drawing.pdf" --output-dir layers_out/
`

### 5. Дообучение YOLO (при наличии GPU)
`ash
python train_yolo.py --data dataset_yolo/dataset.yaml --epochs 30 --imgsz 640 --device 0
`
